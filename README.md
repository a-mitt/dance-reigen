# ダンス霊幻

霊幻が踊るだけのページ。BGM・横揺れの切り替え、褒め言葉・歓声・ペンライト・タップでクラッカー/タンバリン/拍手。

`index.html` 1ファイルで動きます（GitHub Pages で公開）。

## みんなのコメント（ニコニコ風）を有効にする

コメントは Google スプレッドシートに溜まり、「表示」にチェックを入れたものだけが全員の画面に流れます。

1. Google スプレッドシートを新規作成 → 拡張機能 → Apps Script
2. `gas/Code.gs` の中身を貼り付けて保存
3. デプロイ → 新しいデプロイ → 種類「ウェブアプリ」／実行ユーザー「自分」／アクセス「全員」→ デプロイ（初回は権限を許可）
4. 表示されたウェブアプリURL（`https://script.google.com/macros/s/.../exec`）を `index.html` の `const API_URL=''` に入れる
5. 届いたコメントは `comments` シートに出るので、C列「表示」にチェックすると公開されます
